# Canvast Brand Assets

This directory contains the canonical public Canvast visual identity assets.
Only the exact files declared by `asset-manifest.json` belong here; drafts,
review notes, and design-process material are not product assets.

- `canvast-logo.svg` is the canonical square mark for native apps, docs, package pages, and release surfaces.
- `canvast-hero.svg` is the wide banner mark for repository pages, release announcements, and social previews.
- `canvast-logo.tui.txt` is the terminal-safe mark used by the TUI surface and startup/status panels.
- `asset-manifest.json` records project provenance, Apache-2.0 licensing, byte hashes, sizes, purposes, and the exact macOS derived-copy relation.

本目录只保存 Canvast 对外产品使用的规范品牌资产。目录内容必须与
`asset-manifest.json` 的精确清单一致；草稿、评审说明和设计过程材料不得放入本目录。

- `canvast-logo.svg` 是原生 App、文档、软件包页面和发布页面使用的规范方形标识。
- `canvast-hero.svg` 是仓库页面、发布公告和社交预览使用的宽幅横幅标识。
- `canvast-logo.tui.txt` 是 TUI、启动页和状态面板使用的终端安全标识。
- `asset-manifest.json` 记录项目来源、Apache-2.0 许可、文件 hash、尺寸、用途及 macOS 派生副本关系。
